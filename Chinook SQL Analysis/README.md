# SQL Data Analysis Portfolio

## Overview

This repository contains SQL data analysis projects developed using SQLite and real-world datasets. The projects demonstrate practical SQL skills for extracting, filtering, analyzing, and managing structured data through a variety of database operations.

The objective of this portfolio is to showcase proficiency in writing efficient SQL queries, performing relational database analysis, and generating meaningful business insights from structured datasets.

## Project Included

### Chinook SQL Analysis

A comprehensive SQL project based on the Chinook sample database that demonstrates:

- Data retrieval using SELECT statements
- Data filtering using WHERE clauses
- Sorting records using ORDER BY
- Grouping data with GROUP BY
- INNER JOIN and LEFT JOIN operations
- Aggregate functions such as SUM() and AVG()
- Nested queries using subqueries
- Creating and querying SQL views
- Improving query performance using indexes
